# LYCHO

Universal AI agent platform for Pakistani and global businesses.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Supabase (auth + database)
- Upstash Redis
- Lucide React
