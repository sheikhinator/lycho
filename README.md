# LYCHO
### Intelligence. Transmitted.

The universal AI platform. Not a chatbot. Not customer service. A complete AI workforce for any business, in any country, in any language.

## What LYCHO Is

LYCHO deploys specialist AI agents across every function of any business — sales, operations, compliance, research, content, client relations and more. Built for businesses, developers, and individuals globally.

## Platform

- **370+ specialist agents** across 20 sectors
- **Orion** — autonomous nightly optimisation engine
- **Forge** — builds new agents every night automatically
- **Syndicate** — inter-agent communication network
- **Scout** — 5 background agents crawling world data 24/7
- **LYCHO WORLD** — live Stardew-style pixel world visualising your agent society
- RAG knowledge base, voice, web search, MCP server
- 50 countries with geo-intelligence
- Visual workflow builder, developer mode, agent studio
- Full data sovereignty — clients own everything
